# 장비 및 개발 환경 계획

> 아래 목록은 계획서의 조달안입니다. 구매·확보 완료를 의미하지 않습니다.

## 장비 목록

| 항목 | 수량 | 용도 |
| --- | ---: | --- |
| Raspberry Pi 5 | 1 | 영상 분석과 시스템 실행 |
| 웹카메라 또는 카메라 모듈 | 1 | 실내 영상 입력 |
| 터치스크린 디스플레이 | 1 | 상태 표시와 이벤트 확인 |
| HDMI 케이블 | 1 | 화면 연결 |
| M.2 HAT | 1 | NVMe SSD 연결 |
| NVMe SSD | 1 | 운영체제·모델·이벤트 데이터 저장 |
| 전원 어댑터 | 1 | Raspberry Pi 전원 공급 |
| 마이크, 스피커 | 각 1 | 음성 확인과 경보 출력 |
| LAN 케이블 | 선택 | 유선 네트워크 연결 |

케이스는 초기에는 조립이 쉬운 프레임이나 거치 구조를 고려합니다. 보조 배터리는 예산이 남을 때 검토합니다. 구매 전 학과와 팀의 보유 장비를 확인합니다.

## 환경 구축 순서

1. Raspberry Pi, 전원, 저장장치와 화면의 기본 동작을 확인합니다.
2. 카메라 영상을 읽고 화면에 표시하는 최소 동작을 확인합니다.
3. 마이크 입력과 스피커 출력을 각각 확인합니다.
4. 선택한 영상 분석 방법이 장치에서 동작하는지 시험합니다.
5. 이벤트 저장 및 알림용 네트워크 연결을 확인합니다.

운영체제 버전, Python 패키지, 카메라 드라이버, 실행 명령은 장비가 확정되고 실제 설치가 끝난 뒤 기록합니다.
