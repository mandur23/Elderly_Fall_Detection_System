# 장비 및 개발 환경

> 2026-10-25 기준. Raspberry Pi 5, 카메라, 마이크·스피커, 디스플레이는 확보했습니다.

## 장비 목록

| 항목 | 수량 | 용도 | 상태 |
| --- | ---: | --- | --- |
| Raspberry Pi 5 | 1 | 현장 단말 (카메라 전송, 음성 재생·녹음, 현장 화면) | 확보 |
| 카메라 | 1 | 실내 영상 입력 | 확보 |
| 디스플레이 | 1 | 현장 화면 | 확보 |
| 마이크, 스피커 | 각 1 | 음성 확인 | 확보. 마이크는 입력이 작고 잡음이 많아 교체 예정 |
| 감도 좋은 USB 마이크 | 1 | 마이크 교체 (회의용·단일 지향성 등) | **10/26 주문** |
| 서버 PC (팀원 노트북·데스크톱) | 1 | 중앙 서버. 영상 분석과 음성 인식 | 어느 PC를 쓸지, GPU 유무 10/26 확인 |
| 휴대폰 (Chrome 등 최신 브라우저) | 1~2 | 보호자 화면, 카메라 감지 화면 | 팀원 휴대폰 사용 |
| 공유기 또는 핫스팟 | 1 | 시연장 네트워크 (학교 Wi-Fi는 기기 간 통신이 막힐 수 있어 사용하지 않음) | 확인 필요 |
| 휴대폰 거치대 | 1 | 카메라 감지 모드 시연 | 확인 필요 |

## 환경 구축 순서

1. 공유기에 서버 PC, Pi, 휴대폰을 연결하고 서버 PC에 고정 IP를 설정합니다.
2. 서버 PC에서 YOLO-Pose를 돌려 FPS를 측정합니다. GPU가 있으면 CUDA 버전 PyTorch를 설치합니다.
3. 서버 PC에서 faster-whisper 한국어 인식 속도를 확인합니다 (5초 녹음 기준).
4. Pi에서 카메라 프레임을 서버로 보내고 서버에서 받는 속도를 확인합니다.
5. 새 USB 마이크를 연결하고 `alsamixer`로 입력 게인을 조정한 뒤 1~2m 거리에서 녹음·인식을 시험합니다.
6. 서버에 HTTPS 인증서를 설정하고(예: mkcert로 만든 인증서를 휴대폰에 설치), 휴대폰 브라우저에서 보호자 화면 접속과 카메라 권한 허용을 확인합니다.

운영체제 버전, Python 패키지, 서버 PC 사양, 실행 명령은 실제 설치 후 이 문서에 기록합니다.
