# 휴대폰에서 웹 접속하기

휴대폰은 앱을 설치하지 않고 **Chrome 브라우저로 서버 PC에 접속**합니다. 휴대폰 카메라·마이크·웹 푸시는 HTTPS 주소에서만 동작하므로, 서버 PC에서 만든 인증서를 휴대폰이 믿도록 한 번 설정해야 합니다.

## 1. 서버 PC 준비 (처음 한 번)

1. 서버 PC, 휴대폰, Pi를 **같은 Wi-Fi 또는 휴대폰 핫스팟**에 연결합니다. 학교 Wi-Fi는 기기끼리 통신을 막는 경우가 많아 쓰지 않습니다.
2. **Windows: `run_server.bat`을 더블클릭합니다.** (macOS·Linux는 `./run_server.sh`) 처음 한 번은 아래를 자동으로 합니다.
   - Python이 없으면 Python 3.11을 설치하고, 가상환경(`.venv`)을 만들고, 필요한 패키지를 설치합니다(NVIDIA GPU가 있으면 GPU용). 처음에는 몇 분 걸립니다.
   - 인증서 도구(mkcert)를 설치하고 HTTPS 인증서를 만듭니다. **"인증서를 설치할까요?" 창이 뜨면 "예"** 를 누릅니다.
   - `data/rootCA.pem` 파일이 생깁니다. 이 파일을 휴대폰과 Pi에 설치합니다(아래 2번). **이 파일은 다른 사람에게 주지 마세요.** 이 파일로 만든 인증서는 그 휴대폰이 모두 믿게 됩니다.
3. Windows 방화벽 창이 뜨면 **개인 네트워크**에 체크하고 **액세스 허용**을 누릅니다. 이것을 막으면 휴대폰이 접속하지 못합니다. Wi-Fi가 '공용 네트워크'로 되어 있으면 '개인 네트워크'로 바꿉니다.

서버가 켜지면 이 PC 브라우저에 관리자 화면이 열리고, 창에 휴대폰으로 접속할 주소가 나옵니다. 다음부터는 더블클릭하면 바로 켜집니다.

```
  관리자 화면 : https://localhost:8443/admin   (이 PC에서만 열림)
  휴대폰 접속 : https://192.168.0.10:8443   (같은 Wi-Fi·핫스팟)
```

공유기가 서버 PC에 다른 주소를 주면(재부팅 등) `run_server.bat`이 알아서 인증서를 새 주소로 다시 만듭니다. 휴대폰 쪽 설치는 다시 할 필요가 없습니다. 공유기 설정에서 서버 PC 주소를 고정해 두면 편합니다.

## 2. 휴대폰에 인증서 설치 (휴대폰마다 한 번)

`data/rootCA.pem`을 휴대폰으로 옮깁니다(USB, 메신저 "나에게 보내기", 구글 드라이브 등).

**Android**
1. 설정에서 **"인증서"** 를 검색합니다. 제조사마다 메뉴 이름이 다릅니다.
   - 삼성: 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 기기에 저장된 인증서 설치 → **CA 인증서**
   - 그 밖: 설정 → 보안 → 암호화 및 사용자 인증 정보 → 인증서 설치 → **CA 인증서**
2. 경고가 나오면 "설치"를 누르고 `rootCA.pem`을 고릅니다.
3. Chrome을 완전히 닫았다가 다시 엽니다.

**iPhone** (참고: 웹 푸시는 Safari에서 홈 화면에 추가한 아이콘으로 열 때만 됩니다)
1. `rootCA.pem`을 AirDrop이나 메일로 보내 열면 "프로필이 다운로드됨"이 뜹니다.
2. 설정 → 프로필이 다운로드됨 → 설치합니다.
3. 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 그 인증서를 **켭니다**.

## 3. 접속과 회원가입

1. Chrome 주소창에 서버 화면에 나온 주소(예: `https://192.168.0.10:8443`)를 입력합니다.
2. 주소창에 자물쇠가 보이면 성공입니다. "연결이 비공개로 설정되어 있지 않습니다"가 뜨면 아래 문제 해결을 보세요.
3. 회원가입을 합니다. 어르신과 보호자가 각자 가입합니다.
4. 어르신 계정의 **마이페이지**에서 보호자 이메일로 보호자 등록을 요청합니다. 보호자 계정의 마이페이지에서 **수락**합니다.
5. 자주 쓰는 화면은 Chrome 메뉴(⋮)의 **홈 화면에 추가**로 앱처럼 둘 수 있습니다.

## 4. 휴대폰을 카메라로 쓰기 (어르신 쪽)

1. 어르신 계정으로 로그인한 뒤 **카메라** 메뉴를 엽니다.
2. **감지 시작**을 누르고 카메라·마이크 사용을 **허용**합니다.
3. 휴대폰을 거치대에 세워 방이 잘 보이게 둡니다. 충전기를 연결해 두세요.
4. 이 화면을 켜 둔 채 Chrome이 앞에 떠 있어야 합니다. 다른 앱으로 넘어가거나 화면을 끄면 감지가 멈춥니다(화면 꺼짐은 자동으로 막습니다).
5. 넘어짐이 의심되면 휴대폰이 "괜찮으신가요?"라고 묻고 5초 동안 듣습니다. "괜찮아요"라고 말하거나 화면의 **괜찮아요** 버튼을 누르면 해제됩니다.

## 5. 보호자 휴대폰

1. 보호자 계정으로 로그인한 뒤 **보호자 화면**을 엽니다.
2. **알림 소리 켜기**를 누릅니다. 브라우저는 화면을 한 번 누르기 전에는 소리를 낼 수 없기 때문입니다.
3. **마이페이지 → 알림 켜기**를 누르고 알림을 **허용**합니다. 이것이 웹 푸시이며, Chrome을 닫아 두어도 경보 알림이 옵니다. 서버 PC가 인터넷에 연결되어 있어야 합니다.
4. 휴대폰 절전 모드에서는 알림이 늦게 올 수 있습니다. 시연할 때는 절전 모드를 끄세요.

## 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| 주소를 열어도 아무 응답이 없음 | 같은 Wi-Fi가 맞는지, 서버 화면이 켜져 있는지 확인합니다. Windows 방화벽에서 Python을 개인 네트워크에 허용합니다. 학교 Wi-Fi라면 핫스팟으로 바꿉니다. |
| "연결이 비공개로 설정되어 있지 않습니다" | 휴대폰에 `rootCA.pem`이 설치되지 않았거나, 서버 PC 주소가 바뀌었습니다. 2번 설치를 확인하고, `run_server.bat`을 다시 실행하면 인증서를 새 주소로 다시 만듭니다. |
| 카메라 화면에 "카메라는 보안 연결(https://로 시작하는 주소)에서만 쓸 수 있습니다" | 주소를 `http://`로 열었습니다. `https://`로 엽니다. 서버 창에 "HTTPS 인증서가 없습니다"가 보이면 인증서 만들기가 실패한 것이니 창의 앞부분 메시지를 확인합니다. |
| 카메라·마이크 권한을 거부함 | Chrome 주소창의 자물쇠 → 권한 → 카메라·마이크를 허용합니다. |
| 로그인했는데 바로 로그아웃됨 | HTTPS로 접속했는지 확인합니다. |
| "계정이 정지되었습니다" | 서버 PC의 관리자 화면에서 정지를 해제합니다. |
| 웹 푸시가 안 옴 | 서버 PC가 인터넷에 연결되어 있는지, 마이페이지의 알림이 "켜짐"인지, 휴대폰 절전 모드가 꺼져 있는지 확인합니다. 관리자 화면의 "최근 알림 실패"에 이유가 나옵니다. |
| iPhone에서 웹 푸시가 안 옴 | 홈 화면에 추가한 아이콘으로 열어야 웹 푸시를 받을 수 있습니다(iOS 16.4 이상). |
