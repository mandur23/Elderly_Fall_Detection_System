# 프로젝트 계획

> 상태: 계획서 기반 초안 · 최종 제출 목표: 2026년 11월 첫째 주

## 배경과 목적

고령자나 1인 가구에서 낙상이 발생하면 즉시 도움을 요청하기 어려울 수 있습니다. 이 프로젝트는 실내 카메라로 자세와 움직임을 분석해 낙상 의심 상황을 알아차리고, 음성 확인과 알림을 연결하는 비착용형 안전 모니터링 프로토타입을 만드는 것을 목표로 합니다.

## 최종 결과물

- Raspberry Pi에서 카메라, 음성 입출력, 사용자 화면, 이벤트 기록 및 알림 기능을 연동한 시연용 시스템
- 공개 낙상 관련 자료와 안전하게 촬영한 테스트 영상을 이용한 검증 결과
- 실행 방법, 구성 방법, 알려진 한계를 설명하는 문서

## 구현 범위

| 구분 | 계획 내용 |
| --- | --- |
| 필수 | 실시간 영상 입력, 낙상 의심 판단, 음성 상태 확인, 이벤트 기록, 보호자 또는 관리자 알림, 상태 표시 화면 |
| 향후 확장 | 보호자용 원격 화면, 장시간 미동 등 추가 이벤트, 긴급구조 체계 연계 |

의료 진단과 실제 응급기관 자동 신고는 이번 프로토타입의 범위에 포함하지 않습니다.

## 작업 단계

1. 개발 환경과 장치 연결을 확인하고 영상처리 방법을 조사합니다.
2. 공개 모델과 분석 방법을 비교해 Raspberry Pi 환경에 적합한 낙상 감지 방식을 선정합니다.
3. 음성 확인, 알림, 기록, 화면 기능을 각각 구현합니다.
4. 기능을 통합하고 안전한 시연 시나리오로 테스트합니다.
5. 결과와 한계를 정리해 최종 시연 및 발표를 준비합니다.

## 원 계획 일정

| 기간 | 주요 작업 |
| --- | --- |
| 9월 3~4주 | 세부 계획, 개발 환경 구축 |
| 10월 1~3주 | AI 인식 기능 및 음성·알림 등 응용 기능 구현 |
| 10월 3~4주 | 시스템 통합 및 테스트 |
| 10월 4주~11월 1주 | 최종 점검 및 발표 준비 |

이 일정은 제출된 프로젝트 계획서의 안입니다. 실제 완료 여부와 변경 일정은 작업이 진행되면 갱신합니다.

## 확인이 필요한 결정

- 낙상 감지 모델과 판단 기준
- 음성 확인 문구, 응답 방식, 대기 시간
- 알림 채널과 수신자 설정 방법
- 이벤트 기록 형식과 영상·음성 데이터 보관 정책
- 시연 환경에서 사용할 장비의 실제 확보 상태
