# Random Forest 감지 설정

중앙 서버는 YOLO-Pose와 기존 GUI의 42차원 시계열 특징을 이용한 Random Forest를 기본으로 사용합니다. 기기마다 독립된 기록을 유지하고 낙상 의심 시 기존 음성 확인·알림 흐름으로 연결합니다. 모델 파일은 `models/`에 있습니다.

- `FALL_RF_THRESHOLD`: 분석 점수 기준(기본 0.40).
- `FALL_RF_MODEL`: 다른 42차원 모델 파일 경로. 신뢰할 수 있는 모델만 사용합니다.
- `FALL_DETECTION_BACKEND=fsm`: 기존 규칙 기반 감지로 전환합니다.
- 가짜 자세 추정 테스트는 기존 FSM 경로를 사용합니다.

카메라 화면에는 어깨·엉덩이 관절과 분석 점수를 표시합니다. 서버 PC의 관리자 화면(현황 탭의 실시간 영상·낙상 판정)에서도 장면, 분석 점수와 기준, 최근 15초 점수 그래프를 볼 수 있습니다. 녹화 영상은 `python -m server.replay_video 영상.mp4`로 같은 감지기에 넣어 시험합니다. 사람을 인식하지 못하거나 시계열 기록이 모이지 않으면 분석 대기로 표시합니다. 점수는 모델 출력이며 실제 낙상 확률로 검증된 수치가 아닙니다.

기존 모델은 MediaPipe 특징으로 학습되었고 현재 입력은 YOLO-Pose입니다. 카메라, 상황, 사람별 미검출 및 오탐률과 처리 속도를 별도로 시험해야 하며 실환경에서 성능을 보장하지 않습니다.
