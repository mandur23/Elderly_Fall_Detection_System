# 요구사항 초안

> 이 문서는 구현 목표를 정리한 초안입니다. 완료 기능이나 확정된 성능을 뜻하지 않습니다.

## 기능 요구사항

| ID | 요구사항 | 시연 시 확인할 내용 |
| --- | --- | --- |
| F-01 | 카메라 영상을 입력받아 화면에 현재 상태를 표시한다. | 카메라 연결 및 실시간 입력 상태 확인 |
| F-02 | 영상에서 사람의 자세와 움직임을 분석해 낙상 의심 상황을 판정한다. | 정상 동작과 낙상 의심 시나리오의 구분 결과 확인 |
| F-03 | 낙상 의심 시 음성 안내를 재생하고 사용자 상태를 확인한다. | 안내 출력과 응답 처리 확인 |
| F-04 | 확인 절차의 결과에 따라 경보 여부를 결정한다. | 확인됨, 미응답 등 상태별 처리 확인 |
| F-05 | 주요 이벤트를 시간과 상태와 함께 기록한다. | 발생 및 처리 이력 조회 확인 |
| F-06 | 필요한 경우 보호자 또는 관리자에게 알림을 전달한다. | 설정된 시험 수신처로 알림 전달 확인 |
| F-07 | 화면에서 현재 상태와 주요 이벤트를 볼 수 있다. | 상태 변화와 이벤트 표시 확인 |

## 통합 조건

- 카메라, 마이크, 스피커, 화면이 Raspberry Pi 기반 시연 환경에서 함께 동작해야 합니다.
- 영상 분석 방식은 여러 후보를 비교한 뒤 장치의 처리 능력과 테스트 결과를 바탕으로 선정합니다.
- 네트워크나 장치 연결이 끊겼을 때의 표시 및 복구 방식은 구현 과정에서 정의합니다.

## 안전과 개인정보

- 안전한 연출 영상이나 공개 자료로 기능을 검증하고, 테스트를 위해 실제 위험한 낙상을 시도하지 않습니다.
- 사람을 촬영하거나 음성을 수집할 때는 대상자의 동의를 받고, 접근 권한과 보관 기간을 정한 뒤 사용합니다.
- 프로토타입의 경보는 안전을 돕는 보조 수단이며 의료 판단이나 실제 구조 요청을 보장하지 않습니다.

## 확정 전 항목

정확도, 오경보율, 탐지 지연, 음성 응답 대기 시간 등 수치 목표는 아직 확정되지 않았습니다. 모델과 시연 환경을 정한 뒤 측정 방법과 함께 기록합니다.
