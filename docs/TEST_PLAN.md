# 테스트 계획 초안

> 목적은 프로토타입의 기능과 한계를 확인하는 것입니다. 성능 수치는 테스트 후 기록합니다.

## 테스트 자료

- 공개 낙상 관련 자료의 사용 조건을 확인한 뒤 활용합니다.
- 팀 내 테스트 영상은 동의를 받고 안전하게 연출합니다.
- 다양한 조명, 거리, 가림, 일반적인 앉기·눕기 동작을 포함해 오경보를 확인합니다.

## 기능별 확인 항목

| ID | 상황 | 확인할 결과 |
| --- | --- | --- |
| T-01 | 카메라 연결 및 정상 움직임 | 영상 입력과 정상 상태 표시 |
| T-02 | 안전하게 연출한 낙상 의심 영상 | 의심 상태 전환 및 음성 안내 |
| T-03 | 음성 확인에 응답 | 정의한 응답 규칙에 따라 상태 처리 및 기록 |
| T-04 | 음성 확인에 응답하지 않음 | 대기 시간 경과 후 경보·알림 처리 및 기록 |
| T-05 | 앉기·눕기 등 일상 동작 | 불필요한 경보 여부 확인 |
| T-06 | 카메라·마이크·스피커 연결 오류 | 오류 상태 표시 및 복구 방법 확인 |
| T-07 | 알림 경로의 네트워크 장애 | 전달 실패 표시와 재시도 정책 확인 |
| T-08 | 시스템 재시작 | 설정과 이벤트 기록 유지 여부 확인 |

## 시험 도구

| 도구 | 용도 | 관련 항목 |
| --- | --- | --- |
| `python run_demo.py --auto` | 장비 없이 상태 흐름 확인 (앉기·비틀거림·낙상 후 응답/무응답/버튼, 재감지) | T-02~T-05 흐름 |
| `python -m tools.check_device` | 카메라·모델·마이크·스피커·알림 연결 확인 | T-01, T-06, T-07 |
| `python -m tools.evaluate labels.csv` | 영상 파일로 감지율·오경보·지연 측정, `--grid`로 임계값 비교 | T-02, T-05 |
| `python -m unittest discover tests` | 판정 규칙, 이벤트 처리, 알림 재시도, 장치 이상 알림 단위 테스트 | 전체 |

## 측정 및 기록

- 각 시나리오의 입력 자료, 장치 환경, 모델 버전과 판단 기준을 기록합니다.
- 낙상 감지 성공·실패, 오경보, 감지까지 걸린 시간, 음성 확인 결과, 알림 전달 결과를 구분합니다.
- 수치 목표와 합격 기준은 모델 및 시연 환경을 정한 뒤 팀이 합의하여 이 문서에 추가합니다.
- 실패 사례는 재현 조건과 원인을 남기고 수정 후 같은 시나리오로 다시 확인합니다.

이 테스트는 교육용 시연의 동작 확인이며, 의료기기 수준의 성능 검증을 의미하지 않습니다.
